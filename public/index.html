Settings

Credentials stay in this tab and are used only for requests to the configured APIs. When enabled, paper chunks go to the embeddings endpoint and retrieved excerpts go to the chat model.

Open access discovery
Semantic retrieval

On the first question, Ctrl+V embeds the paper and available references in memory, then combines semantic similarity with citation-graph expansion. Compatible with OpenAI-style /embeddings endpoints.

Optional answer synthesis

The optional chat model synthesizes retrieved evidence and adds inline source labels. Without it, Ctrl+V returns the top passages. Local endpoints such as Ollama can omit the key.
