    Configure

    Sources & AI

    Values stay in this tab’s memory and are sent only with requests to the services you configure. Paper chunks go to an embeddings endpoint if you set one; retrieved excerpts go to a chat model if you set one.

    Open-access discovery

    Unpaywall’s free DOI lookup requires a contact email.

    Semantic retrieval (embeddings)

    On the first question, sources are embedded in memory, ranked by cosine similarity plus a lexical signal, then expanded through the citation graph. Any OpenAI-style /embeddings endpoint works.

    Answer synthesis (chat model)

    With a model, retrieved evidence is synthesised with inline [S#] citations. Without one, Ctrl+V returns the top passages themselves.
