    Ctrl+V maps citations; it does not bypass paywalls. Use copies only under their access and reuse terms — an open URL is not a reuse licence. Everything lives in this tab’s memory; close the tab and it is gone.

    ctrl+v — built for open research.

    Sources & AI

    Values stay in this tab’s memory and are sent only with requests to the services you configure. Paper passages go to an embeddings endpoint if you set one; retrieved excerpts go to a chat model if you set one.

    Open-access discovery

    Unpaywall’s free DOI lookup requires a contact email.

    Semantic retrieval

    Sources are embedded in the background once free copies are downloaded, then ranked by meaning plus keywords and expanded through the citation graph. Any OpenAI-style /embeddings endpoint works.

    Answer synthesis

    With a model, answers are written from the retrieved evidence with numbered citations. Without one, Ctrl+V shows the top passages themselves.
